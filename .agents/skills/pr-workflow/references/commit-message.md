# コミットメッセージ

この文書が、コミットメッセージの規約の正本です。

## 形

```
<type>: <日本語の件名>

<本文：なぜこの変更をしたか。何を変えたかはコードを見ればわかるので、理由と背景を書く>

Co-Authored-By: <エージェントの名前> <noreply@...>   ← エージェントが書いたときだけ
```

- 件名は、変更したあとの状態がわかる文にします。「〜を修正」より「〜で日付がずれないようにする」のほうが伝わります。
- 本文は、理由が自明な小さい変更なら省略できます。
- 1 行は 72 文字程度で折り返します。

## type

| type       | 使うとき                             |
| ---------- | ------------------------------------ |
| `feat`     | 利用者から見える機能の追加           |
| `fix`      | 不具合の修正                         |
| `refactor` | 動きを変えないコードの整理           |
| `style`    | 見た目（CSS、レイアウト）の調整      |
| `docs`     | 文書だけの変更                       |
| `chore`    | 依存、設定、ビルド、不要なものの削除 |
| `ci`       | GitHub Actions の変更                |
| `perf`     | 速度の改善                           |
| `security` | セキュリティの修正                   |
| `revert`   | 以前のコミットを取り消す             |

迷ったら、`git log --oneline` で近い変更がどの type を使っているかを見てください。

## 例

実際のコミットから（`git show 4398b5b`）：

```
fix: PC でシラバス検索の背景のグレーが本文の幅にしか付かない問題を直す

背景色を本文の v-container に付けていたため、PC では 720px の本文の範囲だけが薄いグレーになり
両側が白く浮いていた。ホームと同じく、ルートの meta.background で v-main 全体に付ける。
```

`git show 1ef3ace`：

```
chore: Prettier の属性順で :is を先頭にし、ESLint の vue/attributes-order と揃える

attributeGroups の ^(is|v-is)$ は :is に一致せず、:is が v-model の後ろに回っていた。
そのため Prettier と ESLint が BaseBottomSheet.vue の属性順を食い違えて、
コミットのたびに整形差分が出ていた。
```
